Privacy Policy

Listing Tracker is a personal-use automation tool built and operated solely by its developer for their own use. It is not distributed to or used by any other person.

What it does

  • Fetches publicly available apartment listing data from a public real-estate search (no account or login involved).
  • Writes the results to a single spreadsheet file in the developer's own Google Drive, using the drive.file OAuth scope, which only grants access to files this application itself creates.

Data handling

No data is shared with, sold to, or processed by any third party. No data from the developer's Google account other than the single spreadsheet file created by this app is accessed. No advertising, analytics, or tracking is used.

Contact

This is a personal project with no public support channel.
